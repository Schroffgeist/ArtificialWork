# Input Raw Files Directory

This directory is where you should place all your raw research materials that will be processed by the automated academic paper generation system.

## What to Include

Place any of the following file types in this directory:

### Personal Information File (Required)
- **Datos.txt** - Contains your personal information, course details, etc.
- See the included `Datos.txt` for the format

### Research Content Files
- **Notes files** (.txt, .md) - Your research notes, draft content, ideas
- **Bibliography files** (.txt) - List of sources and references
- **Data files** (.csv, .xlsx) - If your paper includes data analysis
- **Draft sections** (.txt, .md) - Pre-written sections or outlines

## Example Files Included

This directory includes several example files to show you the expected format:

- `Datos.txt` - Template for personal/course information
- `sample-notes.md` - Example of how to structure research notes
- `bibliography-sources.txt` - Example bibliography format

## Important Notes

1. **Replace the example content** with your actual research materials
2. **Keep the Datos.txt format** but update with your information
3. **All files in this directory** will be processed by the automation script
4. **File names don't matter** - the system reads all files regardless of name
5. **Remove example files** when you're ready to use your own content

## Supported File Formats

- `.txt` - Plain text files
- `.md` - Markdown files
- `.csv` - Data files (if applicable)
- `.xlsx` - Excel files (if applicable)

The system will analyze all files and extract relevant content, metadata, and references to populate your academic paper template.
